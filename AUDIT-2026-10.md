# Security Audit — 0xNostr-Relay-Finder — 2026-10-20

## Summary

MKStack-derived Vite/React TypeScript app for discovering/evaluating Nostr relays, with a `scripts/crawl` crawler (tsx + ws), a `verifier/` test harness, and NIP/GUIDE documentation. Client-side app: no backend worker, no auth surface, no committed worker secrets. The sensitive surface is limited to the Nostr login stack (same @nostrify/react pattern as 0xsigner — nsec logins persist to localStorage) and the crawler/publish scripts that run operator-side. Light pass: tree, manifest, high-risk files, secret patterns.

Findings: 0 Critical / 0 High / 2 Medium / 2 Low
